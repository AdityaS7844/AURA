==========================================================
07 - MILESTONES (BUILD PLAN + READY-TO-PASTE PROMPTS)
==========================================================

HOW TO USE
1. Start one milestone and attach the referenced documents.
2. Ask the coding assistant to build ONLY that milestone.
3. Run the app and complete its checklist.
4. If it passes, commit to Git before moving on.
5. If it fails, fix only that milestone before continuing.

Golden prompt:
"Build only the milestone below. Read the attached project documents.
Follow 00_PROJECT_OVERVIEW rules and the API/schema contracts. Keep the
code beginner-friendly. When done, stop and list files created, commands
to run and tests performed. Do not start the next milestone."

Suggested commit: one commit per completed milestone.

- AI skipped ahead: "Stop. Only milestone Mx. Remove work outside it."

- Bug: paste full error and relevant file; ask for cause and minimal fix.
- Context long: start a new chat, attach 00 and relevant docs, state
  completed milestones and latest Git commit.
